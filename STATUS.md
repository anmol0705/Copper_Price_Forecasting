## Adjacency Collapse Diagnosed (2026-08-09, Opus)
- [x] F2 root cause fully diagnosed subagent: opus-W model: Opus. Loaded actual trained checkpoints directly (no retraining). DEFINITIVE FINDING: NOT a dead-ReLU problem (sign balance post-training 56.3% negative vs 50.5% at init — statistically indistinguishable; removing ReLU entirely still gives uniform-to-4dp output). REAL MECHANISM: isotropic norm collapse of the graph embeddings. RMS embedding magnitude fell from Xavier-init 0.2885 to 0.0089 (32x), driving bilinear logits (E1@E2^T) from std=0.331 to std=2.8e-4, placing softmax in its first-order/linear regime where it necessarily returns ~1/N regardless of input.
  ZERO DIRECTIONAL LEARNING occurred: two INDEPENDENTLY trained models (tuned h=128/32ep and untuned h=64/43ep, different LR, different everything) have embedding directions with cosine similarity 0.993-0.996 — they only shrank in place along their shared random-init direction, never rotated/differentiated. Rescaling the trained embeddings back to init norm reproduces a softmax spread statistically identical to a fresh random draw. The surviving direction encodes exactly as much structure as noise.
  ROOT CAUSE: Adam's coupled L2 weight_decay=1e-5 (src/trainer.py:41-45) exerts a constant sign-consistent pull toward origin on every embedding parameter; the task gradient reaching these specific parameters is extremely weak (measured ~1e-5/element) because a uniform adjacency is already a near-optimal mean-aggregator given the model's LSTM path carries most of the real predictive signal — so there's almost no loss pressure to differentiate edges. This makes E->0 a SELF-REINFORCING ATTRACTOR (task gradient shrinks proportional to ||E||, decay force stays constant relative to ||E||, so the ratio degrades monotonically and can't recover once started).
  CONFIRMED CAPACITY-INDEPENDENT, EPOCH-DEPENDENT: present at BOTH hidden_dim=64 and hidden_dim=128 with near-identical severity trajectory; severity tracks epochs trained (rms/init: 0.92 @ ep20, 0.47 @ ep25, 0.031 @ ep32, 0.012 @ ep43) not model width. EXPLICIT PREDICTION for the currently-running confound-check experiment: it will show the SAME collapse, since it trains at comparable epoch counts with the same optimizer/decay config — whoever reviews that experiment's results MUST also dump the adjacency matrices and check for the same 1/N pattern, not just compare RMSE/DA.
  Also explains the earlier verification subagent's false-positive "differentiated structure" finding: top-k sparsification is applied AFTER softmax, selecting on values that differ only in the 5th decimal place — the kept-edge SET differs per band only because of residual init-noise-level differences, not learned structure. That's why bands looked "differentiated" (different edges kept) while being functionally uniform (identical weights).
  Fixability assessment: mechanically fixable (exclude graph embeddings from weight decay / switch to AdamW with a zero-decay param group / add temperature scaling / normalize embeddings to unit sphere before dot product) but the DEEPER issue is conceptual — at N=8 nodes a uniform adjacency is already near-optimal for mean-aggregation, so without an explicit auxiliary sparsity/entropy regularizer on the adjacency, there's no reason for gated dot-product graph learning to produce differentiated structure at this scale. This is the honest "fundamental at this scale, not just a bug" framing for Future Work.
  Provided a precise, publication-ready paragraph (see subagent's point 6 in the full report) with exact quantified numbers suitable for direct use in the paper's Discussion/Limitations section.
